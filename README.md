# Studyshelf

StudyShelf – Share Knowledge, Simplify Learning, Grow Together.

About the Project

StudyShelf is a web-based academic resource-sharing platform designed to help students easily upload, share, search, and access study materials in one place. It allows students to organize resources by categories and subjects, making learning easier and more collaborative.

Key Features

- Upload and share study materials.
- Search and filter academic resources.
- Organize resources by subjects and categories.
- Bookmark useful study materials.
- Track downloads and manage content.

Technologies Used

- HTML
- CSS
- JavaScript
