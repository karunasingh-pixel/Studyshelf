# Studyshelf
A searchable academic resource sharing and organizing portal.
StudyShelf is a web-based platform that allows students to upload, share, search, and organize academic resources in one place. It provides features like resource categorization, course tags, search and filters, ratings, bookmarks, download tracking, and content moderation.

Technologies Used: HTML, CSS, JavaScript.

Goal: To make academic resources easily accessible and encourage collaborative learning among students.

StudyShelf – Share Knowledge. Simplify Learning. Grow Together.
